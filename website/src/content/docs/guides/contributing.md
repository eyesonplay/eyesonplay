---
title: Contributing
description: How to help, and the contribution terms.
---

Contributions are welcome: new events, sports, models, fixes and docs.

1. Read [CONTRIBUTING.md](https://github.com/eyesonplay/eyesonplay/blob/main/CONTRIBUTING.md),
   including the contribution licence terms (needed for dual licensing).
2. Run the tests: `pytest` in `event-engine`, `inference-worker` and `backend`;
   `pnpm typecheck && pnpm lint && pnpm test` in `frontend`.
3. Open a pull request. CI runs every suite.

Report security issues privately through
[GitHub security advisories](https://github.com/eyesonplay/eyesonplay/security/advisories/new).
Everyone taking part follows the
[Code of Conduct](https://github.com/eyesonplay/eyesonplay/blob/main/CODE_OF_CONDUCT.md).
